# Muse 自动审批

[English](README.md) | 简体中文

一个 Chrome 扩展，利用已登录 Muse 页面现有的连接，自动处理 [Muse](https://muse.ai) 的审批请求。不点击按钮、不展开菜单，也不需要打开 Approvals 面板。默认关闭。

> **与 Muse 官方无关。** 本项目依赖 Muse 未公开的网页端协议，随时可能失效；自动审批也可能违反 Muse 的服务条款。审批是一道安全检查，自动处理等于跳过它。启用前请先阅读[会批准什么](#会批准什么)，风险自负。

## 安装

1. 从 [Releases](../../releases) 下载 `muse-auto-approve-<版本>.zip` 并解压；或者克隆本仓库，使用其中的 `extension` 目录。
2. 打开 `chrome://extensions`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择解压后的文件夹（或 `extension` 目录）。
4. 打开一个 Muse 会话，等待连接完成。
5. 打开扩展，点**检测连接（只读）**，选择处理范围，再打开**自动处理审批**。每次开启都需要确认“风险自负”。

无需构建，没有依赖。

Release 中还附带签名的 `.crx`。在 Windows 和 macOS 上，Chrome 只允许通过[企业策略](https://support.google.com/chrome/a/answer/7532015)安装 Chrome 应用商店以外的 `.crx`；个人使用请按上面的方式加载 ZIP。

## 会批准什么

- **仅网络连接**（默认）：只处理类型为 `network` 的请求。
- **所有支持的类型**：还包括连接器、设备、浏览器操作、浏览器任务确认、发送媒体和三类结账。这可能替你批准付款或发送内容。目前只有网络请求在真实服务上测试过。

对每个请求，优先使用服务端自己提供的长期允许选项及其范围（例如"始终允许此网站"）；没有则仅允许一次。不会自行扩大范围，也不会批准不认识的请求类型。

长期权限在关闭扩展后仍然有效，需要在 Muse 中撤销。

## 行为

- 审批到达即处理：页面自身的推送事件会唤醒扩展；页面内 3 秒定时和后台 30 秒扫描作为兜底。
- 一次处理所有符合范围的请求（单次最多 20 个），每个提交前都重新确认开关，关闭立即生效。
- 开关只由你关闭。失败或无法确认的审批会显示在弹窗中，60 秒后重试。
- 开启期间，Muse 标签页不会被 Chrome 节省内存功能释放；如果所有 Muse 标签页都已被释放，会重新加载最近使用的一个。
- 弹窗显示最近结果和最近一次自动检查的时间，检查停止时会提示。
- 界面支持英文和简体中文，默认跟随浏览器语言，也可在弹窗顶部手动切换。

需要保留一个已登录的 Muse 会话标签页。页面关闭或被冻结、电脑休眠、登录失效时不会工作。

## 隐私与权限

| 权限 | 用途 |
| --- | --- |
| `https://muse.ai/*` | 在 Muse 页面运行。 |
| `scripting` | 在页面内调用 Muse 的审批方法。 |
| `storage` | 保存设置和最近结果。 |
| `alarms` | 30 秒兜底扫描。 |

扩展不读取会话内容，除了通过 Muse 自己的连接提交审批决定之外不发送任何数据，也不读取 Cookie、令牌或密钥。只保存你的设置、语言以及最近结果的时间和代码。

## 开发

```sh
npm run check   # 语法、JSON 和空白字符检查
npm test        # 要求行、分支、函数覆盖率均为 100%
npm run package # 生成 dist/*.zip；提供 CRX_PRIVATE_KEY 或 --key 时还会生成签名的 .crx
```

需要 Node.js 22.8 或更高版本，无需安装依赖。
